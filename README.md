# TemplateIdeaDesign

A reusable, story-agnostic repository template for structured long-form narrative production.

## Start a new project

1. Read every document in `00_guidance/` before drafting.
2. Define project-specific canon, setting, chronology, and research standards from scratch.
3. Populate the structured categories only with the new project's own material.
4. Do not import story prose, characters, events, historical assumptions, continuity, or status from any source project.
5. After each chapter, run the complete impact audit and synchronize only records actually affected.

## Repository architecture

- `00_guidance/` — production rules and workflow.
- `10_story/` — completed narrative chapters.
- `20_historical_foundation/` — researched real-world or setting baseline, where applicable.
- `30_characters/` — character canon and state.
- `40_relationships/` — persistent relationship state and forms of address.
- `50_world_state/` — durable world conditions.
- `60_decisions/` — significant decisions and consequences.
- `70_timeline/` — long-range and future timeline material.
- `80_story_arcs/` — multi-chapter arcs.
- `90_continuity/` — current state, chronology, open threads, and continuity audits.
- `95_reference/` — supporting research and production references.
- `STATUS.md` — human-readable status for this project only.
- `CHANGELOG.md` — template/project changes only; do not copy source-project history.

All story-specific records begin empty. The guidance documents define process, not inherited canon.
